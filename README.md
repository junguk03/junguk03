## 🎯 Career Goal

**정보보안 전문가**

현재는 다양한 보안 분야(웹 보안, 시스템 보안, 암호학 등)를 폭넓게 학습하며 전문 분야를 탐색 중입니다.


## 🔐 Security Learning Journey

### 현재 학습 중인 분야
- **Web Application Security**: OWASP Top 10 기반 취약점 분석 및 실습
- **Penetration Testing**: Burp Suite를 활용한 웹 모의해킹
- **Wargames**: OverTheWire (Bandit, Natas 등) 풀이
- **Cryptography**: 암호학 기초 이론 학습
- **Network Security**: 네트워크 프로토콜 및 보안

### 학습 방법
- 의도적으로 취약한 웹 애플리케이션 구현 → 공격 → 분석 → 방어
- 직접 개발한 프로젝트들의 보안 취약점 발굴 및 개선
- 워게임 및 CTF 문제 풀이를 통한 실전 능력 향상
- 모든 학습 과정 체계적 문서화
